# zhcrypt GUI v3.0 — Tooltip & 新功能面板设计文档

## 一、Tooltip 机制

### 底层实现

Tkinter 没有原生 tooltip，自定义 `ToolTip` 类：

```
绑定: widget.bind("<Enter>", show) / "<Leave>", hide
显示: 创建 Toplevel 无边框窗口，跟随鼠标
样式: 浅黄底(#ffffcc) + 黑字 + 圆角 + 最大宽度400px
位置: 鼠标下方 +10px 偏移，不超出屏幕
```

### 所有需要 Tooltip 的术语

#### 文本加密标签页

| 术语 | Tooltip 解释 |
|------|-------------|
| 加密密码 | 用于派生加密密钥的密码。每次输入相同的密码+不同的随机盐，会生成不同的密钥。遗忘则数据永久丢失。 |
| 密文 (Base64) | 将二进制加密数据用 Base64 编码为可显示的文本字符串。包含盐值、随机数、加密数据和认证标签。 |
| 盐 (Salt) | 32字节随机数据，与密码一起输入 Argon2id 派生密钥。确保同一密码每次加密产生不同密文。 |
| 一次性密码 | 随机生成的中文词组合口令，显示一次即消失，不存储在任何地方。 |

#### 文件加密标签页

| 术语 | Tooltip |
|------|---------|
| 流式加密 | 将文件分块(每块64KB)独立加密，逐块写入。内存占用仅 ~64KB，支持任意大文件。 |
| 传统加密 | 将整个文件读入内存一次性加密。适合小文件(<64KB)，大文件可能导致内存溢出。 |
| .zhs 格式 | 流式加密文件后缀。每块带独立认证标签，单块损坏不影响其他块。 |
| .zhe 格式 | 传统加密文件后缀。整个文件一个认证标签，任何损坏都导致文件完全不可解密。 |

#### 密钥管理标签页

| 术语 | Tooltip |
|------|---------|
| RSA-4096 | 非对称加密算法，4096位密钥长度。用于加密消息和密钥交换。当前公开分解记录为829位。 |
| Ed25519 | 数字签名算法。发送方用私钥签名，接收方用公钥验证，防止消息伪造和篡改。 |
| X25519 | 椭圆曲线密钥交换算法。用于前向安全(PFS)中计算共享密钥。 |
| 指纹 (Fingerprint) | 公钥的 SHA-256 哈希前16位十六进制字符。用于简短标识和验证公钥身份。 |
| Prekey | 前向安全通信中使用的临时公钥。每次加密都会使用新的 prekey，用后即销毁。 |
| Signed Prekey | 由身份私钥签名的长期临时密钥。在 PFS 中作为接收方的半静态密钥。 |
| One-time Prekey | 一次性临时密钥。用后立即标记已消耗，防重放攻击。 |
| Shamir 秘密共享 | 将密钥分割成多份，任意 N 份可恢复。3-of-5 即 5 份中任意 3 份可恢复。 |
| 3-of-5 阈值 | 5 个恢复份额中，任意 3 个即可重建原始密钥。丢失 3 个则无法恢复。 |

#### 混合模式标签页

| 术语 | Tooltip |
|------|---------|
| 前向安全 (PFS) | 即使长期私钥明天泄露，今天的历史消息仍然安全。通过每次使用临时密钥实现。 |
| ECDH | 椭圆曲线 Diffie-Hellman 密钥交换。双方各自用私钥+对方公钥计算同一共享密钥。 |
| X3DH | 扩展的三重 DH 密钥交换协议。使用三次 ECDH 组合共享密钥，提供双向认证和前向安全。 |
| 混合加密 | 结合 RSA(非对称) 和 AES(对称) 的加密方式。用 RSA 加密临时密钥，用 AES 加密数据。 |
| 数字签名 | 发送方用私钥对消息签名，接收方用发送方公钥验证。可确认消息来源和完整性。 |
| 签名验证 | 接收方用发送方公钥检查消息是否被篡改。通过=未被篡改，失败=内容已被修改。 |

#### 配置标签页 (新增)

| 术语 | Tooltip |
|------|---------|
| 时间成本 | Argon2id 的迭代轮数。越高越安全也越慢。每增加一倍，暴力破解成本翻倍。 |
| 内存成本 | Argon2id 使用的内存量(MB)。内存硬化是抵抗 GPU 暴力破解的关键。256MB 是目前推荐值。 |
| 并行度 | Argon2id 的并行线程数。通常设为 CPU 核心数。不影响安全性，只影响速度。 |
| Prekey 服务器 | 存储和分发临时公钥的服务器。是前向安全通信的基础设施。 |


## 三、实现顺序

```
1. ToolTip 基础类 (gui.py 新增类)
2. 密码强度条 (文本加密标签)
3. 临时口令按钮 + 签名验证状态 (文本加密标签)
4. 文件加密模式选择 + 进度条 (文件加密标签)
5. 身份能力列 + 备份/恢复按钮 (密钥管理标签)
6. Prekey 服务器状态行 (密钥管理标签)
7. 签名 + PFS 复选框 + 结果显示 (混合模式标签)
8. 新增系统配置标签页
```
