安全属性

Security
🔐

端到端加密

服务器只能转发密文，无法解密任何消息内容。所有加解密操作均在客户端完成。

🔄

前向安全

每条消息使用独立密钥。Double Ratchet 确保即使当前密钥泄露，历史消息也无法解密。

✍

身份认证

每条消息附带 Ed25519 数字签名，接收方验证来源真实性，防止中间人冒充。

🛡

完整性保护

AES-256-GCM AEAD 认证加密，任何密文篡改都会导致解密失败，保证消息不被改写。
